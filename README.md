# InvoiceFlow

Create professional invoices in seconds. Free, no signup required.

## Features
- 🚀 Lightning fast invoice creation
- 🔒 100% private (data stays in your browser)
- 📄 Beautiful PDF downloads
- 💰 Free forever
- 🎨 Professional templates

## Tech Stack
- React 18
- Vite
- Tailwind CSS
- Lucide Icons
- jsPDF

## Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

This project is optimized for Vercel deployment:
1. Push to GitHub
2. Import to Vercel
3. Deploy!

Vercel will auto-detect the Vite configuration.
